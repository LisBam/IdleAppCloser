# 空闲自动关闭程序

给一个程序名，**连续一段时间没人操作键盘鼠标，就自动把它关掉**。可以设置开机静默自启。

适合公用电脑、值班机、展厅设备这类场景：人走了，程序不该一直开着。

**整个软件就是一个 exe 文件** —— 不用安装、不要管理员权限、不用装运行库，拷给别人双击就能用。

## 特性

- **单文件绿色版**：不写系统设置、不装服务，删掉文件夹就是卸载干净
- **实时校验程序名**：填完立刻告诉你找不找得到，不用等半小时才发现名字写错了
- **五重防误关机制**（见下），不会把正在用的东西关掉
- **开机自启免管理员权限**，不弹 UAC，随时勾掉
- **自动适配系统缩放**：125% / 150% 缩放下界面文字不会被切
- 依赖 Windows 自带的 .NET Framework，**不需要装 .NET SDK**

## 快速开始

1. 下载 `IdleAppCloser.exe`
2. 双击打开，填上要关闭的程序名，选好时长，点**保存并开始监控**
3. 需要开机自动运行的话，把那个勾打上

窗口可以直接关掉，程序会缩到右下角托盘里继续工作。

想**彻底退出**：右键点击托盘图标 → 退出。托盘菜单里还能暂停监控、打开设置和日志。

## 程序名怎么写

打开任务管理器（`Ctrl + Shift + Esc`）→「详细信息」标签页，在「名称」那一列找到目标程序。

- 带不带 `.exe` 都行：`chrome.exe` 和 `chrome` 效果一样
- 大小写不敏感
- 要关多个程序，用英文逗号分开：`a.exe, b.exe`

界面下方会实时显示 `✔ 找到了：xxx (PID)` 或 `✘ 现在没找到这个程序在运行`，照着提示调整即可。

## 常见问题

**设置了但一直不关？**

把程序目录下 `config.ini` 里的 `LogLevel` 改成 `Debug`，日志里会多出每秒一条的心跳记录：

```
心跳：已空闲 12.3 秒（阈值 300 秒，进程最短存活 300 秒）；目标进程 1 个
```

这一行直接告诉你程序"眼里看到的世界"，对号入座：

| 日志里看到 | 原因 |
| --- | --- |
| 空闲秒数一直很小 | 电脑确实一直有人在操作，这是正常的 |
| 目标进程 0 个 | 程序名写错了 |
| 提示"保护进程在运行" | `ProtectedProcesses` 名单里有程序在跑 |
| 提示"检测尚未校准" | 刚启动的保护期，动一下键鼠即可 |

**日志里说"关闭失败"？**

目标程序是以管理员身份运行的，而本程序不是，权限不够。右键本程序 →「以管理员身份运行」。

**关了但进程还有残留？**

说明目标程序自己拉起了子进程。把 `config.ini` 里的 `KillChildProcesses` 改成 `true`。

**怕目标程序的数据没保存？**

`CloseMode` 保持默认的 `graceful` —— 它会先礼貌地请目标程序自己关闭，给它保存数据的机会，超时才强制结束。

**一锁屏就把程序关了，能改吗？**

把 `config.ini` 里的 `LockedCountsAsIdle` 改成 `false`（默认 `true`，即锁屏立刻算作空闲）。

## 进阶设置

界面上只有三个选项，其余高级设置可以直接编辑程序目录下的 `config.ini`（用记事本打开即可）。
**界面上保存时不会覆盖你手工加的这些项。**

| 选项 | 说明 |
| --- | --- |
| `LockedCountsAsIdle` | 锁屏是否立刻算作空闲，默认 `true` |
| `MinRunSeconds` | 目标程序至少运行多少秒才允许关闭，防止"刚打开就被关" |
| `CloseMode` | `graceful`（先请它自己关，推荐）/ `force`（直接强制结束） |
| `GracefulTimeoutSeconds` | 优雅关闭等待上限，默认 15 秒 |
| `KillChildProcesses` | 是否连子进程一起结束 |
| `ProtectedProcesses` | 这些程序在运行时，绝不关闭目标程序 |
| `SkipWhenFullScreen` | 目标占全屏时跳过（看视频、做演示时有用） |
| `LogLevel` | `Debug` / `Info`（默认）/ `Warn` / `Error` / `Off` |

日志在程序目录的 `logs\` 文件夹里，按天分文件，默认保留 14 天，会自动清理。

## 为什么它不会乱关你的东西

1. **进程最短存活时间**：目标程序必须已经运行够久才会被关。你刚点开它的时候，"打开"这个动作本身就刷新了空闲计时，所以绝不会出现刚打开就被关掉。

2. **启动校准**：程序启动时如果电脑已经空闲很久（比如开机自启时人恰好不在），它会先按兵不动，直到观察到一次真实的键鼠操作才开始工作，避免一上来就批量误杀。

3. **锁屏判定做了交叉验证**：只凭单一信号判断锁屏，在权限不足时会被误判，配合"锁屏即关"就会立刻误杀。程序要求两个条件同时成立才认定锁屏，否则保守地当作没锁。

4. **计时不受开机时长影响**：Windows 的计时器约 49.7 天回绕一次，程序用无符号运算处理，天然正确。

5. **数值合理性确认**：时间设得特别短（少于 30 秒）时，保存前会让你确认一次。

## 自己编译

改过源码后，在项目目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1
```

产物是 `dist\IdleAppCloser.exe` 和使用说明，用的是 Windows 自带的 .NET Framework 编译器，**不需要装 .NET SDK**。

## 系统要求

- Windows 7 / 8 / 8.1 / 10 / 11
- .NET Framework 4.x（Win7 以上系统自带，无需额外安装）
